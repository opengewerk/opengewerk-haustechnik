# Aufnehmen

Hier nehmen Sie den Bestand vor Ort auf: einen Raum auf einem Geschoss oder eine Anlage in einem Gebäude, auf Wunsch in einem seiner Räume. Das geht ohne Netz.

## Kurzanleitung

1. Den Ort wählen: Liegenschaft, Gebäude, Geschoss, Raum.
2. „Anlage aufnehmen“: die Anlagenart wählen, die Merkmale ausfüllen und das Typenschild fotografieren.
3. Der Anlage ein Etikett zuordnen, indem Sie es scannen.
4. Im Büro schlägt die Akte der Anlage danach ihre Pflichten vor.
