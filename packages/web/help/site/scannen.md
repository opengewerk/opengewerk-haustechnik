# Scannen

Halten Sie die Kamera auf das Etikett einer Anlage oder eines Raums. Das Gerät öffnet die Seite dazu, mit Angaben, Pflichten, letzten Nachweisen und Dokumenten.

- **Noch keiner Anlage zugeordnet:** Das Etikett ist frei. Öffnen Sie die Anlage und wählen Sie „Etikett zuordnen“.
- **Nicht auf diesem Gerät:** Was das Etikett nennt, hält dieses Gerät nicht. Mit Netz abgleichen und noch einmal scannen.
- **Etikett gesperrt:** Das Etikett gilt nicht mehr.
- **Kein Etikett:** Der Code gehört nicht zu dieser Anwendung.
