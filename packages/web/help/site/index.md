# Start

Der Start zeigt, was für Sie heute und in dieser Woche ansteht: Rundgänge, Prüfungen, Aufträge und Ablesungen, die Ihnen zugeteilt sind. Ein Tipp öffnet den Vorgang.

Was hier steht, liegt auf dem Gerät. Sie können es ohne Netz erledigen. Das Gerät gleicht ab, sobald es wieder eine Verbindung hat.
