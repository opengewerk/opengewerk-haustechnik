# Vom Mangel zum Auftrag

Ein Mangel wird gemeldet, bekommt eine Frist, wird als Auftrag erledigt und danach nachgeprüft. So bleibt nachvollziehbar, wer was wann festgestellt und behoben hat.

## Schritt für Schritt

1. Den Mangel melden: vor Ort an der Anlage oder am Raum, in einem Rundgang oder einer Prüfung, oder im Büro unter „Mängel“. Ein Foto hilft.
2. Die Klasse gibt die Frist vor, bis zu der der Mangel beseitigt sein soll.
3. Im Büro aus dem Mangel einen Auftrag anlegen und zuteilen.
4. Vor Ort den Auftrag auf dem Start öffnen, erledigen, Notizen schreiben und „Abschließen und unterschreiben“.
5. Im Büro den Auftrag abnehmen oder mit Begründung zurückweisen.
6. Den Mangel nachprüfen: „Nachgeprüft“ schließt ihn, „Nicht behoben“ öffnet ihn wieder.
