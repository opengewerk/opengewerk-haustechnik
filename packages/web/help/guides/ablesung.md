# Ablesung

Zähler werden zu einem Stichtag im Monat abgelesen, in einer Runde über die Zähler einer Liegenschaft. Die Runde geht ohne Netz.

## Schritt für Schritt

1. Die Ablesung auf dem Start öffnen. Sie steht dort, sobald sie fällig wird.
2. Zähler für Zähler den Stand eintragen.
3. Fragt das Gerät bei einem Stand nach, weil er nicht zum letzten passt, den Stand prüfen. „So übernehmen“ bestätigt ihn.
4. Mit Netz gleicht das Gerät ab, und die Stände stehen im Büro unter „Zähler“.

## Im Büro

1. War ein Stand falsch, „Stand berichtigen“ an der Messstelle.
2. Wurde ein Zählwerk gewechselt, „Tausch eintragen“.
3. Den Stichtag geben die Einstellungen vor. Eine Messstelle kann davon abweichen.
