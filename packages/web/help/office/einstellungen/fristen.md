# Fristen

Hier legen Sie fest, wie viele Tage vorher die Anwendung an eine fällige Pflicht und an die Frist eines Mangels erinnert, und wer erinnert wird.

Erinnert wird per E-Mail, wenn der Mailserver des Betreibers eingerichtet ist, und per Push auf den Geräten, auf denen jemand es eingeschaltet hat. Was fällig wird, steht unabhängig davon unter [Fristen](/fristen).
