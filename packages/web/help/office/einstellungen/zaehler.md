# Zähler

Hier legen Sie fest, an welchem Tag im Monat der Stand jedes Zählers fällig ist. Zu diesem Stichtag wird die Ablesung fällig, die vor Ort als Runde über die Zähler einer Liegenschaft erledigt wird.

Eine einzelne Messstelle kann davon abweichen. Ihr eigener Stichtag steht an der Messstelle unter [Zähler](/zaehler).
