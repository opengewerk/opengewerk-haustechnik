# Nummernkreise

Hier steht, wie Anlagen, Aufträge und Nachweise nummeriert werden. Jeder Kreis hat ein Muster und eine nächste Nummer; daneben steht, wie die nächste heißen wird.

Im Muster steht `{year}` für das Jahr, in dem die Nummer vergeben wird, und `{number}` für die laufende Nummer. `{number:5}` füllt sie mit Nullen auf fünf Stellen auf. Ein neues Muster gilt ab der nächsten Nummer, vergebene Nummern bleiben, wie sie sind.

Die nächste Nummer lässt sich nur erhöhen, etwa um die Zählung einer Vorgängeranwendung fortzusetzen. Eine vergebene Nummer wird nie ein zweites Mal vergeben. Ändern kann die Nummernkreise nur, wer Einstellungen ändern darf.
