# Aufgaben

Aufgaben sind kleine Dinge, die jemand erledigen soll und die keinen Auftrag brauchen: ein Anruf, eine Rückfrage, eine Bestellung. Eine Aufgabe kann an einer Liegenschaft, einem Gebäude, einem Raum, einer Anlage oder einem Vorgang hängen.

## Kurzanleitung

1. „Neue Aufgabe“ anlegen und sagen, für wen sie ist.
2. Wer sie bekommt, sieht sie hier und vor Ort im Menü.
3. „Erledigt“ hakt sie ab.
